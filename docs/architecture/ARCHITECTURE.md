# Architecture Baseline v0.3

## Selected Technology Baseline

```text
Web framework: Next.js
Language: TypeScript
Package manager: pnpm
Database: PostgreSQL
```

Exact application versions were selected at Milestone 0. PostgreSQL 18 and the
managed provider topology were selected at Milestone 1.

## Logical Components

```text
Browser
  ├─ Public Website (/tr, /en)
  └─ Admin (/admin)
        ↓
Next.js Application Server
  ├─ public rendering/content
  ├─ admin/auth/RBAC
  ├─ career/contact submissions
  ├─ media/file access
  ├─ publication/preview
  └─ audit/operations
        ↓
PostgreSQL
Protected/Public Object Storage
Malware Scanner
Email Provider
Monitoring/Logging
```

## Security Boundaries

Public:

- reads published content,
- submits approved forms,
- never accesses protected CV.

Admin:

- MFA,
- authenticated,
- server-authorized,
- Turkish UI.

## Provider Topology

```text
Vercel fra1 (Next.js Functions)
  ├─ Neon PostgreSQL 18 / AWS eu-central-1
  ├─ Auth0 EU tenant / MFA Always
  ├─ Amazon S3 eu-central-1
  │    ├─ public
  │    ├─ protected
  │    ├─ quarantine → GuardDuty Malware Protection → EventBridge
  │    └─ encrypted database backup/export
  ├─ Amazon SES eu-central-1
  └─ Sentry Germany + AWS CloudWatch/EventBridge
```

Public static assets can be delivered by Vercel's global CDN. Server execution,
primary database, protected objects, scanning and email use the selected EU
regions. Environment tenants/projects/buckets are separate.

Provisioning, account owners, paid plan selection, DPA/subprocessor review,
legal data-transfer assessment and alert recipients remain `TBD` production
gates. See ADR-009 and ADR-010.

## Portability and Recovery

- PostgreSQL schema/migrations are provider-independent SQL generated by
  Drizzle.
- Standard `pg_dump`/`pg_restore` is the exit and independent-backup path.
- S3 object keys and metadata remain application-owned; access is never tied to
  public bucket URLs for protected data.
- Auth0 user export limitations and migration procedures must be rehearsed
  before any provider exit.
