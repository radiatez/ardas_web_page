# Ardaş Logo Brief

## Status

No final Ardaş logo currently exists.

This document defines the direction for a future logo; it is not a finished logo asset.

## Brand Name

Primary:

```text
ARDAŞ
```

Secondary descriptor where needed:

```text
Yedek Parça
```

English descriptor may be used only where context requires it:

```text
Automotive Aftermarket
```

## Desired Character

The logo should feel:

- established,
- corporate,
- precise,
- strong,
- modern,
- industrial,
- trustworthy,
- suitable for a 30+ year company.

It should not feel:

- like a repair shop,
- like a racing team,
- like a tuning brand,
- like a car manufacturer imitation,
- like an e-commerce startup.

## Preferred Direction

Start with a **strong wordmark**.

Potential visual idea:

- custom treatment of the `A`,
- subtle geometric/forward-motion cue,
- compact mark that can work independently at favicon/app-icon sizes,
- clean geometry suitable for warehouse signage, boxes, documents, web and uniforms.

Avoid obvious clichés:

- wrench inside logo,
- car silhouette,
- piston,
- steering wheel,
- checkered racing flag,
- tire outline.

## Color

Final corporate palette is **TBD**.

Do not automatically use ABB red.

A serious high-contrast palette with one strong accent is preferred, but final colors must be approved as part of brand design.

## Required Future Deliverables

When logo design is finalized, create:

- primary horizontal logo,
- compact/symbol version,
- light-background version,
- dark-background version,
- monochrome version,
- SVG,
- PNG exports,
- favicon/app icon,
- clear-space rules,
- minimum size rules,
- color tokens.

## Temporary Website Behaviour

Until final assets exist:

- use `ARDAŞ` as a clean text wordmark,
- keep dimensions/layout compatible with a future SVG,
- do not create a fake permanent logo inside production code.
