## Locales

```text
tr
en
```

Default:

```text
tr
```

Root:

```text
/ → /tr
```

## Missing Locale Variant

Direct request to unpublished locale:

```text
404
```

Language switch:

```text
equivalent published page
→ equivalent route

otherwise
→ target locale homepage
```

Do not silently serve Turkish copy on English URLs.

## Locale-Aware Publication

Every localized public entity that can appear independently must support:

```text
publish_status
published_at
scheduled_publish_at
scheduled_archive_at nullable
```

Applies to:

- PageLocale
- BrandLocale
- ProductGroupLocale
- LocationLocale
- JobPostingLocale
- relevant LegalPage/PageLocale
- MediaLocale where independently managed for accessibility/caption completeness

## Publication States

```text
Draft
Published
Archived
```

## Preview

Draft preview requires secure authenticated/preview access and must not be indexable.

## Slug Changes

Published slug change creates redirect history:

```text
old localized path
→ 301
→ current localized path
```

See data model `SlugRedirect`.

## System Strings

Navigation, validation, form labels, buttons and errors come from locale resources.

## Stable Form IDs

Display labels are never database identifiers.

## SEO

Localized pages:

- title
- description
- canonical
- hreflang alternates
- localized social metadata
- sitemap only when published
